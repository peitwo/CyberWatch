## 1. 结论

登录页右侧那个"白色圆脸"错位，**不是**表情元素本身被摆歪了，而是
**三个共享类被"半覆盖"**：`dashboard.css` 里为 Dashboard 的 230×160 版式量好的
坐标（`left:80px/top:47px`、`inset:7px 20px`、`top:6px/right:5px`）泄漏进了登录页，
而登录页又用一套自造的字号（`20px` + `letter-spacing:12px`）覆盖了共享排版。

结果有两条独立的破坏路径，都能量化：

1. **整块位移**：白脸中心偏离圆球中心 **33.5px**（纵向），圆球自身也没居中；
2. **表情折行跑出脸外**：`letter-spacing:12px` 把 `•　ᴗ　•` 撑到约 126px，
   而白脸只有 95px 宽 —— 表情被迫折行，末尾那颗「•」（腮红）掉到白脸下方 **14px** 之外。

修复后：脸心与球心 **Δ = (0, 0)**，眼睛左右各 26.9px（差 0.00）、嘴巴偏移 0.00px、
腮红左右各 36.01px（差 0.00）、全部 5 个字形与两行行盒都在白脸内。
**Dashboard 的吉祥物逐字段零变化。**

| 验收项 | 结果 |
|---|---|
| 几何探针（390 / 720 / 1440 × 登录页 + Dashboard） | **46 / 46 通过** |
| 宽度扫描（640 → 1600，步长 40） | **491 项断言，0 失败** |
| 真浏览器回归（既有 37 项验收） | **37 / 37 通过** |
| 自动化测试（全量 pytest） | **297 / 297 通过**（248.59s） |
| 新增永久守卫测试 | **4 条**（架构测试 16 → 20），且已验证"会红" |

## 3. 根因

### 3.1 CSS 是"部分覆盖"语义，少写一个属性 = 继承别人的值

`dashboard.css` 与 `login.css` 同时被登录页加载。`.login-art .mascot{...}` 的特异度更高，
于是**只有它声明过的属性**会生效；**没声明的属性照旧沿用 `.mascot{...}` 里的值**：

```css
/* 改前：dashboard.css */
.mascot{position:absolute;left:80px;top:47px;width:95px;height:83px;...}

/* 改前：login.css —— 写了 display/字号/字距，却漏了 left/top */
.login-art .mascot{position:absolute;display:grid;gap:6px;place-items:center;
  color:#8a6b96;font-size:20px;letter-spacing:12px;font-weight:700}
```

`left:80px / top:47px` 这两个值是为 Dashboard 的 230×160 `.hero-art` 量的，
它们原样落到了登录页上 —— 这就是 33.5px 位移的全部来源。`.orb` 的 `inset:7px 20px`
同理（absolutely positioned + 四个方向都给值 = 过约束，`right/bottom` 被忽略）。

### 3.2 表情元素没有共享类名 → 拿不到共享排版

```html
<!-- dashboard.html：正确 -->
<div class="mascot"><span class="ears">◠　◠</span><span class="eyes">•　ᴗ　•</span></div>
<!-- login.html：改前 -->
<div class="mascot"><span>◠　◠</span><span>•　ᴗ　•</span></div>
```

缺 `ears`/`eyes` 就拿不到 `.ears{font-size:29px;line-height:1}` /
`.eyes{font-size:24px}`，只能吃登录页自造的 `20px + letter-spacing:12px`。
`letter-spacing` 会加在**每个**字形之后（含最后一个），于是 `•　ᴗ　•` 宽到约 126px，
超过 95px 的白脸 → 折行 → 尾字符挂到白脸下方。

> 顺带说明：`.ears` 里的 `◠　◠` 画出来是**眼睛**，`.eyes` 里的 `•　ᴗ　•`
> 画出来是**腮红 + 嘴巴** —— 类名与语义是反的。本轮**没有改名**（改名要同时动
> Dashboard，属于另一件事），已在 `dashboard.css` 里就地注释说明。

### 3.3 为什么单测抓不到

- `TestClient` 不跑布局、不实现 CSS 级联 —— `.mascot` 是宽 80px 还是 230px，它一无所知；
- 这个缺陷 100% 出在 CSS 级联与**定位上下文**上，只有真浏览器的 `getBoundingClientRect()`
  才有答案。

## 4. 修复

三处外科式改动（沿用仓库的单行压缩风格，不重排、不批量格式化）：

### 4.1 `static/dashboard.css`：把"摆在哪"收进各自的作用域

```diff
- .orb{position:absolute;inset:7px 20px;...}
+ .hero-art .orb{position:absolute;inset:7px 20px;...}
- .mascot{position:absolute;left:80px;top:47px;width:95px;height:83px;...}
+ .mascot{width:95px;height:83px;...}                    /* 共享组件：白脸的长相 */
+ .hero-art .mascot{position:absolute;left:80px;top:47px} /* 仅 Dashboard 的摆位 */
- .one{top:6px;right:5px}.two{bottom:6px;left:17px}.three{top:16px;left:35px}
+ .hero-art .one{...}.hero-art .two{...}.hero-art .three{...}
- @media(max-width:1050px){... .mascot{left:35px}}
+ @media(max-width:1050px){... .hero-art .mascot{left:35px}}
```

**区分原则**：`.mascot / .ears / .eyes` 描述"长什么样" → 全局共享；
`left / top / inset` 描述"摆在哪" → 只对某个版式有意义，必须带前缀。

### 4.2 `static/login.css`：只留定位

```diff
- .login-art .mascot{position:absolute;display:grid;gap:6px;place-items:center;color:#8a6b96;
-   font-size:20px;letter-spacing:12px;font-weight:700}
+ .login-art .mascot{position:absolute;left:50%;top:50%;transform:translate(-50%,-50%)}
```

白脸几何、字体、配色全部交还给共享组件。`.orb` 的 `inset` 泄漏也随之消失
（Dashboard 那份 `inset` 已被收进 `.hero-art`），圆球恢复为 `place-items:center` 正常居中。

### 4.3 `templates/login.html`：复用同一段标记

```diff
- <div class="mascot"><span>◠　◠</span><span>•　ᴗ　•</span></div>
+ <div class="mascot"><span class="ears">◠　◠</span><span class="eyes">•　ᴗ　•</span></div>
```

改完后两页的 `<div class="mascot">…</div>` **逐字节相同**。

## 6. 关于 390px 与 720px

`login.css` 有一条既有规则 `@media (max-width:760px){.login-art{display:none}}`
—— **390 与 720 下右侧装饰区整体隐藏，卡片单列占满**（与 Dashboard 在 ≤720px
隐藏 `.hero-art` 的行为一致）。实测这两个视口下：无横向溢出、卡片完整、无残留元素。

所以本轮的"圆脸正常"可以这样读：

- **1440**：圆脸渲染，46 项几何断言全过；
- **800 → 1600 全线**：扫描 491 项断言全过；
- **390 / 720**：装饰区按既有设计隐藏，页面无溢出、无破损。

如果你想在窄屏也保留吉祥物（这是**独立的产品决定**，不是缺陷），有两条现成路线，
我可以另开一轮做：

| 方案 | 做法 | 代价 |
|---|---|---|
| A. 放宽断点 | `760px → 700px`，720 视口两栏 + 居中吉祥物 | 701–760px 区间开始走两栏；白脸是固定 95px，此时球只有约 157px，脸会显得偏大（比例 0.60 vs 桌面 0.41） |
| B. 窄屏横幅 | ≤700px 时不隐藏，收成卡片上方一条 130px 高的横幅，用 `transform:scale(.52)` 等比缩小 | 卡片总高 +150px，小屏需要滚动；引入第三种版式 |

我按"发布前最小范围"**没有动它**，也没有改 `760px` 这个断点。
